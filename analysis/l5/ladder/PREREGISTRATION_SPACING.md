# Preregistration — ladder coordinate system (offsets from the moving touch)

**Fixed before any result.** S3 untouched and frozen at `8b20a259…87df`.
No live orders. No next-action model is built; the deliverable is a
**coordinate system** or an explicit failure to find one.

## 0. Central question

> Can the 5–15-level lower-bound ladder be generated by a **small stable set
> of offsets from the moving touch**?

If yes, report that coordinate system. If no, say so — a null is a complete
answer here.

## 1. Two issues settled before the protocol, not after

### 1a. Two of the five named spacing models are the same model
Polymarket's price grid **is $0.01**, so one tick *is* one cent:

| named candidate | status |
| --- | --- |
| uniform ticks | **M1** |
| uniform cents | **≡ M1** — identical by the grid definition |
| increasing spacing deeper from touch | **M2** |
| probability-scaled spacing | **M3** |
| volatility-scaled spacing | **M4** |

A win by M1 may **not** be reported as two independent confirmations. This
is the fifth such collapse in this program; the check is routine.

### 1b. "Probability of eventual consumption" is a selection tautology
A level becomes inferable **only because a fill occurred there**. Therefore
`P(any consumption | inferable) ≡ 1.0` **by construction** and is not a
measurable quantity.

The measurable substitute, fixed now, is
**`P(full consumption to the 80 ceiling | level inferable)`**, i.e. the
share of inferable levels whose cumulative consumption reaches
`80 − 0.75` shares. Reported under that name, never as "probability of
consumption".

## 2. Reconstruction

For every BTC15m window, every inferred L5 **maker** level is expressed
relative to the **contemporaneous touch at the first second that level
becomes inferable** (its first attributable fill). Bids only — the
crossed-book defect is ask-side; the archive's own `crossed` column is read
and exposure reported.

Distributions built over:

| quantity | definition | status |
| --- | --- | --- |
| **level number** | rank of the level by depth below touch at first inference, 1 = nearest | observed |
| **offset from touch** | `best_bid − level_price`, in ticks and in dollars | observed |
| **latent quantity** | cumulative consumption attributable to that level's clip | **LOWER BOUND on exposed quantity** |
| **lifetime lower bound** | `last_fill − first_fill` at that level | **LOWER BOUND** |
| **P(full consumption)** | as defined in §1b | observed, conditional |

**Individual fill quantity is never used as intended order quantity.**
**No unfilled order is inferred.** Latent quantity is a floor, because
consumption is all that is observable.

## 3. Spacing-model comparison

Per window/outcome, take the sorted offsets from touch of levels inferable
within the window and compare consecutive gaps.

| model | form |
| --- | --- |
| **M1** uniform | gap(k) = c |
| **M2** increasing with depth | gap(k) = a + b·k, with b > 0 |
| **M3** probability-scaled | gap(k) = c · p(1−p), p = contemporaneous touch |
| **M4** volatility-scaled | gap(k) = c · σ, σ = realized sd of the **contract price** over the trailing 60 s |

**M4 uses contract-price volatility, not BTC volatility.** There is no
settlement index (G-STRIKE failed at 10/12), so no BTC-derived σ is used
and none is implied.

**Comparison metric, fixed now.** Each model's parameters are fitted on 11
windows and scored on the held-out 12th (**LOWO**). Score = median L1 error
in the predicted offset of each level by rank.

*Bar:* a model wins if its LOWO median L1 is **≥20 % better** than the next
best **and** it wins **≥9/12** held-out windows. Otherwise
**NOT_DISCRIMINATED**.

## 4. Are new levels at constant offsets from the moving touch?

For every newly-inferable level, record its offset from the contemporaneous
touch. Then:

**T-STABLE.** Is the distribution of first-inference offsets tight?
*Bar:* IQR ≤ **2 ticks** ($0.02) pooled, **and** per-window median within
±2 ticks of the pooled median in ≥**9/12** windows.

**T-SET.** If T-STABLE passes, report the **smallest offset set** that
covers ≥80 % of newly-inferable levels, as integer ticks from touch, and
state its coverage. That set *is* the coordinate system.

**T-RECENTER.** When the touch moves by ≥1 tick, do new levels reappear at
the same offsets relative to the **new** touch?
*Bar:* median absolute change in offset-from-touch across a touch move
≤ **1 tick**, in ≥9/12 windows.

## 5. Stability of the 5–15 level ladder

Does the lower-bound ladder have stable **spacing** (as opposed to stable
count)? Reported as the per-window IQR of consecutive gaps, pooled and
per-window. No bar is set for "stable" beyond the model comparison in §3,
so that a qualitative word cannot do work the numbers do not support.

## 6. Standing limits, restated

- Every level count and lifetime is a **lower bound**; cancels and
  unfilled orders are invisible.
- Same-second events cannot distinguish concurrency from fast reposting.
- The exact strike/settlement index remains **UNIDENTIFIABLE**; nothing
  here uses one.
- No model is selected by settlement P&L.
