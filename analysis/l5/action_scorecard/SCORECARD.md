**Models (existing implementations, re-fitted on train rows only — neither is
modified, replaced or rebuilt):**

* **M_V1** — the deployed state-only lookup, `src/polymarket_l5/action_model.py`:
  `state_key = price band × tte bucket × |residual| bucket` → modal action.
* **M_V1_1** — the deployed v2 family, `src/polymarket_l5/action_model_v2.py`
  plus the V1.1 sequential-context fix: the same base state **+ `last_rel`,
  `last_size`**, α=10 shrinkage, `full → base → marginal` backoff.
* **M_T** — Stage-3 timing, `analysis/l5/act_wait/model.py` family:
  `(base state, since_last bucket)` → modal gap bucket.

**Baselines, every one fitted on the same train rows and scored on the same
test rows** (pinned by `test_baselines_and_models_are_scored_on_identical_rows`):
majority / persistence (window-local, strictly backward-looking) /
marginal-frequency random (seeded, reported with its analytic `Σp²`).

**SIDE is not a field the model emits.** It is derived from the predicted
relation and the sign of the standing residual; on a flat book the model is
*silent* about side, and those 133 rows are counted as silent rather than given
a free guess. The bootstrap column uses an all-rows denominator (silence =
miss), which is why the side lift reads −0.0127 there and −0.0083 in the
accuracy table.

## 3. Breakouts — 5m vs 15m, and the repo's existing eras/regimes

No new regime is invented. Eras are `analysis/l5/norebate/q1.py`
(`FIRST_REBATE = 2026-04-21`); regimes are the primary change points in
`analysis/l5/canon_regimes.json` (R1 03-19→04-24, R2 04-25→06-22,
R3 06-23→08-18, R4 08-19→08-31).

**Coverage, stated before the numbers:** the canonical sequence holds 22 active
days — 2026-03-19..04-21 and 2026-08-28..31. **Regimes R2 and R3, and era
`E2_EARLY_REBATE`, have ZERO rows here.** That is a gap in OUR collection, not
in L5's activity (the full 760,817-fill corpus covers them). The global holdout
falls entirely inside E3/R4, so E1 and R1 are additionally scored under a
**within-stratum chronological split** with the model re-fitted on that
stratum's earlier windows only.

Caveat: 5m is 1,989 test rows against 18,855, and 5m rows are almost entirely

Two era facts matter more than the lifts:

1. **Era E1 is the only era where the model beats every baseline on both

   model's modal answer is `q5-15`. The deployed size behaviour is an August
   artefact.

## 5. Unscorable fields, and exactly what is missing

| field | status | what is missing |
|---|---|---|
| **PRICE RELATIVE TO TOUCH (offset in ticks from the same-side best bid)** | **UNSCORABLE** | There is **no contemporaneous order book** for L5's windows (`analysis/l5/L5_TOUCH_PROXIMITY.md` §0: *"L5's distance from the touch is NOT COMPUTABLE"*), and the deployed model emits no touch-relative price at all, so neither the prediction nor the truth exists. Missing artifact: a per-second top-of-book series covering L5's traded windows. The only book on disk is Zenodo 22084977 (BTC15m, 2026-08-21..24, `analysis/l5/historical_l2/`), whose overlap with the canonical sequence is **zero windows**, and in which **26.4% of L5's maker fills price at or above the prevailing ask** — a complete-set mint, not a placeable touch offset. The two baselines the lane asked for ("always offset 0", "repeat previous offset") are therefore **also unscorable**, not merely unreported. |
| **WITHDRAW** | **UNSCORABLE** | No order-lifecycle data anywhere: the corpus is a *fill* tape. A cancel is indistinguishable from a wait — "L5 waited" and "L5 quoted and was not hit" are the same observation (`L5_OPERATING_MODEL.md` §2a). Missing artifact: L5 order placement/cancel events, which the venue does not serve. |
| **WAIT** | **not re-scored here** | WAIT is not a row in the fill-transition space; it needs the opportunity grid already built and scored as Stage 1 in `analysis/l5/act_wait/`. Those numbers stand and are cited, not duplicated: PR-AUC 0.2565 vs base rate 0.1428 at H=2s, 0.7088 vs 0.4951 at H=10s, and `last_rel = open` PR-AUC **0.21** — i.e. the **market-ENTRY decision remains unvalidated** because no corpus records markets L5 considered and declined. |

Everything else requested by the lane (side, exposure action, size/clip
envelope, timing bucket) is scored above, plus `switch`, which the repo's own
`EXTEND_AND_SWITCH.md` vocabulary makes derivable from the fill tape.

## 6. Reading this against the operating model

* `L5_OPERATING_MODEL.md` §2a names same-side run length as the strongest
  replicating predictor of `EXTEND` (P = 0.66 unconditional, 0.733 at run 4+).
  This scorecard is the cost of that finding: **a predictor that good is also
  what makes a naive persistence rule nearly unbeatable.** Run persistence is
  the signal *and* the baseline, so the model inherits almost no incremental
  skill from it.
* The honest version of the fidelity claim is therefore: **our model reproduces
  L5's autocorrelation. There is no evidence in this holdout that it reproduces
  L5's decision.** Per the validation standard in `CLAUDE.md`, that is not
  replication.
* Nothing here changes any live spec, fingerprint or probe discipline. Lane D is
  measurement only.
